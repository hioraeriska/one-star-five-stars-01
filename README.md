An alien tourist gives planet Earth a one-star review — and still admits the food was excellent. One sentence, 139 characters: a complaint about rent, leaking skies, and a taco that nearly saved the species.

## Run

```sh
node main.ts
```

This writes the review sentence to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default).
